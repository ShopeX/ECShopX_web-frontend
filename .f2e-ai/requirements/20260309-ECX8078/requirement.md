## 目标用户 / 场景

- **用户**：在 Web 商城（PC 或手机浏览器 H5）完成下单、待支付的买家
- **场景**：
  1. 结算页提交订单成功后跳转至支付页（带订单号等参数）
  2. 订单列表或订单详情点击「去支付」跳转至支付页（带订单号）
- **目标**：在支付页选择支付方式 → 点击「去支付」→ 展示支付码 → 用户扫码完成后展示支付成功（或跳转）

## 核心能力

1. **支付方式**：通过接口获取支付方式列表，页面上支持选择
2. **去支付**：用户点击「去支付」后，调用查询订单支付信息等接口，展示对应支付码（如二维码）
3. **支付结果**：轮询/查询支付结果，直至成功或超时；支付成功后展示成功态或跳转
4. **异常与返回**：支付超时或失败时提示，支持重试或返回；支持从订单列表/详情带订单号进入

## 验收标准

- [ ] 支付方式通过接口获取并展示，用户可选择
- [ ] 点击「去支付」后展示对应支付码（如二维码）
- [ ] 轮询/查询支付结果，直到成功或超时
- [ ] 支付超时或失败时有提示，支持重试或返回

- [ ] 页面与交互符合 Figma 设计稿（5 个节点），PC 与 H5 响应式正常
