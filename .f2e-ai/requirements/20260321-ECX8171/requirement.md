# 需求文档 — 20260321-ECX8171

## 需求来源

- 平台：Teambition
- 任务号：ECX-8171
- 任务标题：物流详情组件开发
- 创建时间：2026-03-21

## 原文摘要

开发一个可复用的物流详情组件，覆盖 PC 与 H5 双端，并接入多个页面 / 场景复用；前端对接现有物流查询接口 `POST /wxapp/trackerpull`，按 Figma 设计稿完成还原与联调。

## 分类

- 类型：新功能组件开发 / 交互增强
- 模块：订单 / 个人中心

## 目标用户 / 场景

已登录用户在订单相关页面查看某笔订单的物流详情，包含快递单号、物流公司、物流轨迹时间线，并可在 PC / H5 端通过统一组件能力完成查看与关闭。

## 核心能力

1. **可复用物流详情组件**：抽离为可在多个页面 / 场景复用的前端组件，而不是仅服务单一页面。
2. **双端适配能力**：PC 端按右侧抽屉形态展示，H5 端按底部弹层形态展示。
3. **物流信息展示**：展示标题、快递单号、物流公司、轨迹时间线，以及关闭交互。
4. **接口联调能力**：对接现有 `POST /wxapp/trackerpull` 查询物流轨迹数据。

## 验收标准

- 按 PC 与 H5 Figma 设计稿完成 UI 还原
- 完成 `POST /wxapp/trackerpull` 的前端联调
- 组件能够在多个页面 / 场景复用，至少覆盖当前订单列表与订单详情相关入口
- PC 与 H5 两端均可正常打开、查看、关闭物流详情

## 约束

- 复用现有接口，不新增后端接口
- 需兼容现有订单模块数据结构与页面风格
- 组件需支持响应式差异化呈现，但尽量沉淀为统一复用实现

## 优先级

- 来自当前 Teambition Sprint，视为当前迭代内需求

## 待确认项

- “多个页面 / 场景”最终上线范围是否仅包含当前订单列表页与订单详情页，还是还包含其他订单相关入口
- 是否直接升级现有 `OrderDetailLogistics.vue` 为通用组件，还是拆成“通用内容组件 + PC/H5 容器壳子”
- 快递单号复制交互是否需要 toast、埋点或其他反馈
- 接口请求中的 `order_type` 取值枚举需以后端 / 产品口径最终确认为准
