# 05-i18n: 国际化基础设施

本技能包定义了多语言支持的技术实现细节及 RTL（从右至左）布局适配标准。

## 1. 技术栈与配置 (Nuxt i18n)

- **多语言源**: 位于 `app/locales/` 的 JSON 文件。
- **默认语言**: `zh` (简体中文)。
- **持久化**: 用户选定的语言状态存储在 Cookie 中，实现页面刷新后的自动保持。

## 2. 布局适配 (RTL)

针对阿拉伯语 (`ar`) 等从右至左的语言：
- **方向检测**: 通过 `html[dir="rtl"]` 进行全局样式控制。
- **逻辑方向类**: 优先使用 Tailwind 的逻辑方向类（如 `ms-4` 代替 `ml-4`, `pe-2` 代替 `pr-2`）。
- **镜像效果**: 对具有方向性的图标（如返回箭头）使用 `scale-x-[-1]`。

## 3. 翻译管理规范

- **禁忌**: 严禁在脚本层进行拼凑式翻译（如 `t('count') + count + t('unit')`），应使用占位符翻译（如 `t('items_count', { count })`）。
- **动态加载**: 除了核心公共包，各模块可根据需要实现翻译文件的 **Lazy Loading** 以降低首屏提及。

## 4. 类型安全
- 鼓励使用可以从 JSON 提取 Key 的 TypeScript 工具函数，确保在调用 `t()` 时具有代码补全和拼写校验。
