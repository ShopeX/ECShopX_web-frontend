## 可复用组件建议

结合项目现有 `app/components` 与设计稿：

| 现有组件             | 建议用法                                   | 说明                                                                              |
| -------------------- | ------------------------------------------ | --------------------------------------------------------------------------------- |
| **UIcon**（Nuxt UI） | 支付方式选中勾选、加载态图标               | 已用 `i-heroicons-check`，与设计稿勾选一致                                        |
| **ECButton**         | 「去支付」「查看订单」「继续购物」「重试」 | 支持 variant=dark（#0f0f10）、outline；可统一主/次按钮样式                        |
| **ECLoading**        | 支付方式列表、订单信息加载中               | 需加载态时替换纯文案 "加载中..."                                                  |
| **ECPrice**          | 订单金额、待支付金额展示                   | 若项目统一用 ECPrice 做金额格式与货币符号，可替换当前 `orderAmountFormatted` 展示 |
| **ECModal**          | 失败/超时弹窗（若产品改为弹窗）            | 当前为内联区块，若交互改为弹窗可复用                                              |
| **NuxtLink**         | 返回购物车、查看订单、继续购物             | 已用，保持即可                                                                    |

**未复用说明**：

- **BCOrderSummary**：为结算页「商品数量、商品总计、运费、优惠、总计」结构，与支付页「订单金额 + 剩余时间」不同，不建议直接复用。
- **ECCheckbox**：支付页为支付方式单选（卡片点击选中），非勾选框，未使用 ECCheckbox。

| **PaymentFooter**        | PC 底栏：待支付金额 + 去支付按钮（固定宽度或右对齐）                   | 2183:8717             | 低                         |
| **PaymentStickyBar**     | H5 吸底栏：待支付金额 + 全宽去支付按钮                                 | 2876:4843             | 低                         |
| **PaymentQrcode**        | 支付方式名称 + 二维码容器（200×200、阴影）+ 扫码说明文案               | 2849:8104             | 低                         |
| **PaymentResultSuccess** | 支付成功主文案 + 金额 + 查看订单/继续购物按钮组                        | 2199:669 / 2885:6692  | 低                         |

## 设计要点（按节点）

### 1. 立即支付（PC）— 2183:6786

- **顶部区块**
  - 左：主文案「订单提交成功，请尽快付款。」（16px Medium，#191a1d）
  - 左：副文案「剩余支付时间」+ 倒计时「00 : 28 : 42」（14px，次亚黑 #4a5565 / 主黑 #191a1d）
  - 右：「订单金额」+ 金额「¥ 10,500.00」（14px 标签 #6a7282；24px Medium 金额 #191a1d）
- **支付方式**
  - 标题：「请选择以下支付方式」（14px #4a5565）
  - 卡片：微信支付、支付宝、银联支付；横向排列；选中态为边框 `#0f0f10`（主题色）+ 右下角勾选图标
- **底部栏（PaymentPage）**
  - 「待支付」+ 金额（14px #4a5565 + 24px #191a1d）
  - 主按钮「去支付」：宽 200px，背景 `#0f0f10`，白字 14px Medium

### 2. 支付码 — 2849:8104

- 标题区：支付方式图标 +「微信支付」+「使用微信扫码支付」（16px Medium + 12px Regular，#4a5565）
- 二维码：200×200，白底、圆角 8px、阴影 `0px 4px 8px #e1e7f0`
- 说明：「打开手机端微信」「扫一扫继续付款」（12px #4a5565）

### 3. 支付成功（整页）— 2199:669

- 主文案：「支付成功 ¥ 10,500.00」（24px Medium，#191a1d，行高 48px）
- 主按钮「查看订单」：背景 `#0f0f10`，白字，px-32 py-16
- 次按钮「继续购物」：白底、描边 `#0f0f10`、字 #191a1d
- 下方为「猜你喜欢 / 最近浏览」等推荐区（按项目是否实现为准）

### 4. H5 选择支付方式 — 2876:3380

## 样式与规范

- **主题色**：`#0f0f10`（主按钮、选中边框）
- **主文字**：`#191a1d`
- **次要/说明**：`#4a5565`、`#6a7282`
- **边框/分割**：`#e5e7eb`（浅灰 line）
- **字体**：Noto Sans SC（Medium/Regular）、Inter（金额等）
- **响应式**：PC 与 H5 共用同一套逻辑，布局与节点 1/4、2、3/5 对应；H5 吸底栏、支付方式纵向排列。
