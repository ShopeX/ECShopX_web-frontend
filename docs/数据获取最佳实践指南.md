# 数据获取最佳实践指南

## 🎯 架构原则

### 清晰的分层架构

```
页面层 (Pages)
    ↓ 直接调用
API 层 (app/api/*)
    ↓ 使用
HTTP 层 (useHttp)
    ↓ 基于
网络层 ($api)
```

### 职责分离

- **页面层**: 处理用户交互，管理页面状态
- **API 层**: 封装业务接口，处理数据转换
- **HTTP 层**: 处理请求逻辑，缓存和重试
- **工具层**: 提供通用的数据获取工具

## 📋 使用规范

### 1. 简单数据获取

**场景**: 组件内部的简单数据请求

```vue
<script setup lang="ts">
import { useItemApi } from '~/api/item'

const itemApi = useItemApi()

// ✅ 推荐：直接调用 API 层
const loadData = async () => {
  try {
    const { data, error } = await itemApi.getList(params)
    if (error.value) throw error.value

    // 处理数据
    items.value = data.value?.data?.list || []
  } catch (err) {
    console.error('数据加载失败:', err)
  }
}
</script>
```

### 2. SSR 数据获取

**场景**: 需要服务端预渲染的页面数据

```vue
<script setup lang="ts">
import { useItemApi } from '~/api/item'

const itemApi = useItemApi()

// ✅ 推荐：使用 useAsyncData + API 层
const { data, pending, error, refresh } = await useAsyncData(
  'product-list', // 缓存键
  async () => {
    const response = await itemApi.getList(params)
    return response.data.value?.data
  },
  {
    // 监听响应式依赖
    watch: [() => route.query],
    server: true, // 启用 SSR
    default: () => null,
  }
)
</script>
```

### 3. 复杂数据管理

**场景**: 需要复杂状态管理和缓存的数据

```vue
<script setup lang="ts">
import { useDataFetch } from '~/composables/useDataFetch'
import { useItemApi } from '~/api/item'

const itemApi = useItemApi()

// ✅ 推荐：使用通用工具 + API 层
const { data, pending, error } = useDataFetch(
  () => `product-list-${JSON.stringify(params)}`, // 动态缓存键
  () => itemApi.getList(params),
  {
    watch: [() => route.query],
    server: true,
  }
)
</script>
```

### 4. 带重试的关键请求

**场景**: 重要的业务数据，需要重试机制

```vue
<script setup lang="ts">
import { useItemApi } from '~/api/item'

const itemApi = useItemApi()

// ✅ 推荐：使用带重试的 API 方法
const { data, pending, error } = await useAsyncData(
  'critical-data',
  () => itemApi.getListWithRetry(params), // 使用重试版本
  {
    server: true,
  }
)
</script>
```

## 🛡️ 错误处理

### 统一错误处理模式

```typescript
// ✅ 标准错误处理
const loadData = async () => {
  try {
    const { data, error } = await itemApi.getList(params)

    // 检查响应错误
    if (error.value) {
      throw error.value
    }

    // 检查业务错误
    if (!data.value?.data) {
      throw new Error('响应数据为空')
    }

    // 处理成功数据
    return data.value.data
  } catch (err) {
    // 统一错误处理
    console.error('API 请求失败:', err)

    // 用户友好的错误提示
    if (err.status === 404) {
      showError('数据不存在')
    } else if (err.status >= 500) {
      showError('服务器异常，请稍后重试')
    } else {
      showError('请求失败，请重试')
    }

    throw err
  }
}
```

## 🚀 性能优化

### 1. 合理使用缓存

```typescript
// ✅ 根据数据特性设置缓存
export function useItemApi() {
  return {
    // 频繁变化的数据 - 短缓存
    getList(params) {
      return useHttp('/goods/items', {
        query: params,
        cache: 'default',
        key: `items-${JSON.stringify(params)}`,
      })
    },

    // 相对稳定的数据 - 长缓存
    getCategories() {
      return useHttp('/goods/categories', {
        cache: 'force-cache', // 强制缓存
        key: 'categories',
      })
    },
  }
}
```

### 2. 智能预加载

```vue
<script setup lang="ts">
// ✅ 预加载下一页数据
const preloadNextPage = () => {
  if (hasMore.value) {
    const nextParams = getApiParams(currentPage.value + 1)
    // 预加载但不等待结果
    itemApi.getList(nextParams)
  }
}

// 在用户接近底部时预加载
const { arrivedState } = useScroll(window)
watch(
  () => arrivedState.bottom,
  (isBottom) => {
    if (isBottom) {
      preloadNextPage()
    }
  }
)
</script>
```

## 📊 状态管理

### 1. 页面级状态

```vue

const total = ref(0)
const loading = ref(false)
const error = ref<Error | null>(null)

// 计算属性
const hasMore = computed(() => items.value.length < total.value)

</script>
```

### 2. 全局状态（Pinia Store）

```typescript
// stores/product.ts
export const useProductStore = defineStore('product', () => {
  const items = ref<Item[]>([])
  const categories = ref<Category[]>([])

  // Actions 中使用 API 层
  const fetchItems = async (params: ItemListParams) => {
    const itemApi = useItemApi()
    const { data, error } = await itemApi.getList(params)

    if (error.value) throw error.value

    items.value = data.value?.data?.list || []
    return items.value
  }

  return {
    items: readonly(items),
    categories: readonly(categories),
    fetchItems,
  }
})
```

## 🚫 反模式

### ❌ 避免的做法

```typescript
// ❌ 不要在页面中直接使用 useHttp
const { data } = useHttp('/goods/items', { query: params })

// ❌ 不要创建不必要的抽象层
const useProductData = () => {
  const itemApi = useItemApi()
  return itemApi.getList() // 只是简单转发，没有价值
}

// ❌ 不要混合不同的数据获取方式
const data1 = await useAsyncData('key1', () => itemApi.getList())
const data2 = useHttp('/goods/items', { query: params })

// ❌ 不要忽略错误处理
const { data } = await itemApi.getList(params)
items.value = data.value.data.list // 可能报错
```

## 📚 进阶使用

### 1. 条件式数据获取

```vue
<script setup lang="ts">
// 只在登录后获取用户相关数据
const { data: userProducts } = await useAsyncData(
  'user-products',
  () => itemApi.getUserProducts(),
  {
    server: false, // 客户端获取
    skip: () => !user.value?.id, // 条件跳过
  }
)
</script>
```

### 2. 并行数据获取

```vue
<script setup lang="ts">
// 并行获取多个数据源
const [{ data: products }, { data: categories }, { data: brands }] = await Promise.all([
  useAsyncData('products', () => itemApi.getList(params)),
  useAsyncData('categories', () => itemApi.getCategories()),
  useAsyncData('brands', () => itemApi.getBrands()),
])
</script>
```

### 3. 增量数据更新

```typescript
// 增量加载更多数据
const loadMore = async () => {
  const nextPage = currentPage.value + 1
  const { data } = await itemApi.getList({ ...params, page: nextPage })

  if (data.value?.data?.list) {
    // 追加到现有数据
    items.value.push(...data.value.data.list)
    currentPage.value = nextPage
  }
}
```

通过遵循这些最佳实践，你可以构建出清晰、高效、易维护的数据获取架构。记住关键原则：**保持简单，职责单一，直接调用 API 层**。
