# API 使用指南

## 📋 概述

项目采用模块化的 API 调用方式，通过统一的 `api` 对象来调用不同模块的 API，提供清晰的代码结构和良好的维护性。

## 🚀 新的调用方式

### 基本用法

```typescript
import { api } from '~/api'

// 获取商品列表
const response = await api.item.getItemList(params)

// 获取商品详情
const detail = await api.item.getItemDetail({ id: '123' })

// 带重试机制的API调用
const retryResponse = await api.item.getItemListWithRetry(params)
const retryDetail = await api.item.getItemDetailWithRetry({ id: '123' })
```

### 在页面中使用

```vue
<script setup lang="ts">
import { api } from '~/api'
import type { IItemListParams } from '~/types/api/item'

// 构建API参数
const buildParams = (): IItemListParams => ({
  page: '1',
  pageSize: '20',
  item_type: 'goods',
  main_category: '',
  is_tdk: '1',
  type: 'list',
  company_id: '1',
})

// 方式1：直接调用
const loadProducts = async () => {
  try {
    const response = await api.item.getItemList(buildParams())
    if (response.data.value?.data) {
      // 处理数据...
    }
  } catch (error) {
    console.error('加载失败:', error)
  }
}

// 方式2：使用 useAsyncData (推荐用于SSR)
const { data, pending, error, refresh } = await useAsyncData(
  'products',
  () => api.item.getItemList(buildParams()),
  {
    server: true,
    watch: [() => route.query],
  }
)

// 方式3：使用 useLazyAsyncData (推荐用于客户端)
const { data, pending, error } = await useLazyAsyncData('products', () =>
  api.item.getItemList(buildParams())
)
</script>
```

## 📚 API 模块

### Item 模块 (`api.item`)

#### 商品列表相关

```typescript
// 获取商品列表
api.item.getItemList(params: IItemListParams)

// 获取商品列表（带重试）
api.item.getItemListWithRetry(params: IItemListParams)
```

**参数说明：**

```typescript
interface IItemListParams {
  page: string // 页码
  pageSize: string // 每页数量
  item_type: string // 商品类型
  main_category: string // 主分类
  is_tdk: string // TDK标识
  type: string // 类型
  company_id: string // 公司ID
  brand_id?: string // 可选：品牌ID
  sort?: string // 可选：排序方式
  start_price?: number // 可选：起始价格
  end_price?: number // 可选：结束价格
  keywords?: string // 可选：关键词
}
```

#### 商品详情相关

```typescript
// 获取商品详情
api.item.getItemDetail(params: IItemDetailParams)

// 获取商品详情（带重试）
api.item.getItemDetailWithRetry(params: IItemDetailParams)
```

**参数说明：**

```typescript
interface IItemDetailParams {
  id: string // 商品ID
}
```

## 🔄 向后兼容

为了保持向后兼容，旧的 `useItemApi()` 方式依然可用：

```typescript
// 旧方式（仍然支持）
import { useItemApi } from '~/api/item'
const itemApi = useItemApi()
const response = await itemApi.getList(params)

// 新方式（推荐）
import { api } from '~/api'
const response = await api.item.getItemList(params)
```

## 🎯 最佳实践

### 1. 使用统一导入

```typescript
// ✅ 推荐
import { api } from '~/api'

// ❌ 不推荐
import { useItemApi } from '~/api/item'
```

### 2. 合理使用重试机制

```typescript
// 对于重要的数据获取，使用带重试的方法
const response = await api.item.getItemListWithRetry(params)

// 对于实时性要求高的场景，使用普通方法
const response = await api.item.getItemList(params)
```

### 3. 正确处理错误

```typescript
try {
  const response = await api.item.getItemList(params)
  // 处理成功响应
} catch (error) {
  // 处理错误
  console.error('API调用失败:', error)
}
```

### 4. 使用 TypeScript 类型

```typescript
import type { IItemListParams, IItemDetailParams } from '~/api'

const params: IItemListParams = {
  // 类型安全的参数
}
```

## 🔧 扩展新模块

未来添加新的 API 模块时，遵循以下步骤：

### 1. 创建模块文件

```typescript
// app/api/user.ts
class UserApi {
  private http = useHttpMethods()

  getUserProfile(id: string) {
    return this.http.get(`/user/${id}`)
  }
}

export const userApi = new UserApi()
```

### 2. 更新统一导出

```typescript
// app/api/index.ts
import { userApi } from './user'

export const api = {
  item: itemApi,
  user: userApi, // 新增模块
}
```

### 3. 使用新模块

```typescript
import { api } from '~/api'

// 调用用户API
const profile = await api.user.getUserProfile('123')
```

## ⚡ 性能优化

### 1. 合理使用缓存

所有 API 方法都支持自动缓存，相同参数的请求会被缓存以提高性能。

### 2. 避免重复请求

使用 `useAsyncData` 或 `useLazyAsyncData` 包装 API 调用，可以自动避免重复请求。

### 3. 服务端渲染

所有 API 都支持 SSR，在服务端预取数据以提高首屏加载速度。
