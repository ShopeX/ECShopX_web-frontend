# 开发计划：ECX-8101 我的订单页面开发

## 1. 目标
开发“我的订单”页面（`/account/orders`），支持多端响应式（PC + H5），实现订单列表展示、状态筛选以及核心业务操作（支付、取消、确认收货、删除等）。

## 2. 关键任务

### 任务 A: 基础构建与 API 适配
- **类型定义**：在 `app/types/order.ts` 中补齐订单状态枚举及接口返回类型（建立 API 字段与前端展示的映射）。
- **API Client 校准**：
  - 更新 `OrderApiClient.ts` 中的路径（如 `/wxapp/orders`、`/wxapp/order/confirmReceipt` 等），确保与最新 Apifox 文档对齐。
- **Composable 增强**：
  - 优化 `useOrders.ts`，支持基于状态 Tab 的数据筛选及请求参数转换。

### 任务 B: 核心组件开发 (Responsive)
- **`OrderTabs`**：
  - PC 端：横向排列的 Tab 列表。
  - H5 端：支持横滑的弹性布局。
  - 支持状态：全部、待支付、待收货、待自提、售后、待评价。
- **`OrderCard`**：
  - 承载订单头（商铺名、状态）、商品明细（图片、标题、SKU、单价、数量）、汇总（总件数、总价）、操作区。
  - PC 端：列表式布局。
  - H5 端：卡片式布局，按钮底部靠右对齐。
- **`OrderActionGroup`**：
  - 逻辑封装：根据 `order_status` 展示“取消订单”、“立即支付”、“确认收货”、“申请售后”、“删除订单”等按钮。

### 任务 C: 页面集成 (`app/pages/account/orders.vue`)
- **布局实现**：
  - PC：集成在个人中心框架内（`AccountMenu` 侧边栏）。
  - H5：实现带下拉菜单的头部（设计稿 2896:3528）。
- **列表控制**：
  - 集成 `ECPagination` 处理分页（PC）。
  - H5 后续可考虑无限加载或复用分页。
- **交互逻辑**：
  - 切换 Tab 时重置页码并重新加载。
  - 操作（如取消订单）确认后立即刷新列表。

### 任务 D: 联调与适配
- **状态映射**：将后端的 `pay_status`、`delivery_status` 等组合映射为前端语义化的状态文案。
- **支付跳转**：对接现有 `/payment` 支付链路。

## 3. 验收标准
- [ ] PC/H5 双端样式还原高度匹配 Figma。
- [ ] 状态 Tab 切换功能正常，数据请求准确。
- [ ] “立即支付”正确跳转至支付页。
- [ ] “取消订单”、“确认收货”、“删除订单”操作成功且列表同步更新。
- [ ] 页面加载态（Skeleton）与空态展示符合预期。
