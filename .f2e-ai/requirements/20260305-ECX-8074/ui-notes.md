## 设计令牌（Figma 文本样式）

- **16meduim / 16meduima**：Noto Sans SC Medium 16px，行高 20/16
- **14regular / 14meduim**：Noto Sans SC Regular/Medium 14px，行高 20
- **12regular / 12meduim**：Noto Sans SC Regular/Medium 12px，行高 16
- **价格16medium / 价格14meduim / 价格14 / 价格36meduim**：Inter，用于金额展示（16/14/24px 等）

实现时需对齐项目现有字体与 Token（见 `app/assets/css/main.css` 的 `@theme` 与 `--ui-*`）。

## 左栏结构（结算表单）

1. **配送信息**：单选「快递配送」「门店自提」
2. **地址**
   - 快递：地址卡片列表（默认标记、姓名、手机、地址、编辑）、「+添加新地址」
   - 无地址：红色「请添加地址」+「+添加新地址」
   - 门店自提：收货人姓名、手机号；省/市选择、「查找附近门店」、自提点列表（名称、地址、电话、单选）
3. **优惠券**：入口文案如「满500减100 >」
4. **积分抵扣**：用户可用积分、本单最大可用积分、勾选「使用积分」「全额抵扣」（可选输入）
5. **发票信息**：勾选「需要电子发票」；企业发票时：抬头、公司名称、税号、地址、开户行、银行账号等

---

## 右栏结构（订单摘要）

- 商品件数、商品图、品名、款号/款式/尺寸、数量、单价
- 费用明细：商品总计、运费（免费）、优惠
- 总计金额
- 勾选「我同意隐私政策以及销售条款」
- 主按钮「立即支付」

---

## 实现注意

- **端范围**：当前为 Web 端商城，仅做 **PC + 移动端 H5** 的响应式适配，不包含小程序或 APP。设计稿为 PC 端布局（左右分栏），实现时需按项目规范做响应式：PC 保持双栏，移动端 H5 可改为单栏/折叠等适配。
- 代码参考为 React + Tailwind，需转换为本项目技术栈（Vue 3 + Nuxt + 项目 Tailwind/主题），并遵循现有组件（EC* / BC*）与样式约定。
