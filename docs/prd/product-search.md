# 商品搜索功能

## 背景

当前商品列表页（`/collections/all`）支持品牌筛选、价格筛选和排序，但**缺少关键词搜索功能**。用户无法通过输入商品名称或关键词快速找到想要的商品，影响购物体验和转化率。

## 用户故事

1. **作为**一个购物用户，**我想要**在商品列表页点击搜索图标打开搜索抽屉，**以便**输入关键词快速找到想要的商品。

2. **作为**一个购物用户，**我想要**看到热门搜索和历史搜索，**以便**更快地完成搜索。

3. **作为**一个购物用户，**我想要**搜索结果能与现有筛选条件组合使用，**以便**进一步缩小商品范围。

## 验收标准（AC）

### AC1：搜索入口

- [ ] 搜索图标位于**全局 Header 左上角**（与菜单图标相邻）
- [ ] 点击搜索图标，打开左侧抽屉（与菜单抽屉交互方式一致）
- [ ] 抽屉支持点击关闭按钮或遮罩层关闭

### AC2：搜索抽屉

- [ ] **PC 端**：从左侧滑出（与菜单抽屉一致）
- [ ] **H5 端**：从左侧滑出（与菜单抽屉一致）
- [ ] 顶部显示搜索输入框，带占位符"甄选手袋礼品"
- [ ] 输入框支持清空按钮
- [ ] 输入框支持回车键触发搜索
- [ ] 显示"热门搜索"区块，标签可点击
- [ ] 显示"历史搜索"区块，标签可点击
- [ ] **PC 端**：热门搜索和历史搜索两列并排显示
- [ ] **H5 端**：热门搜索和历史搜索横向 flex-wrap 排列

### AC3：搜索执行

- [ ] 输入关键词后，按回车或点击搜索，触发商品列表刷新
- [ ] 点击热门搜索/历史搜索标签，自动填充并执行搜索
- [ ] 搜索关键词与现有筛选条件（品牌、价格、排序）可叠加使用
- [ ] 搜索关键词同步到 URL 参数（`?keyword=xxx`）
- [ ] 刷新页面后能从 URL 恢复搜索状态
- [ ] 搜索成功后自动关闭抽屉

### AC4：搜索历史

- [ ] 搜索成功后，自动将关键词存入历史记录（localStorage）
- [ ] 历史记录最多保留 10 条，超出时移除最旧的
- [ ] 支持清空历史记录功能

### AC5：搜索结果

- [ ] 搜索无结果时显示空状态提示
- [ ] 搜索结果显示匹配的商品数量
- [ ] 搜索关键词在结果区域有提示（如"xxx 的搜索结果"）

## 非目标（Non-goals）

- 搜索联想/自动补全（后续迭代）
- 搜索结果高亮（后续迭代）
- 语音搜索（不做）

## 测试点

### Happy Path

1. 点击搜索图标 → 抽屉滑出 → 显示搜索框和热门/历史搜索
2. 输入关键词 → 按回车 → 显示匹配商品 → 抽屉关闭
3. 点击热门搜索标签 → 自动搜索 → 抽屉关闭
4. 点击历史搜索标签 → 自动搜索 → 抽屉关闭
5. 搜索后 → 选择品牌筛选 → 结果同时满足搜索词和品牌
6. 带搜索参数的 URL → 刷新页面 → 搜索状态正确恢复

### Edge Cases

1. 输入空白关键词 → 不触发搜索
2. 搜索无匹配结果 → 显示空状态
3. 输入特殊字符 → 正常处理（不报错）
4. 快速连续输入 → 防抖处理，只触发最后一次
5. 历史记录超过 10 条 → 移除最旧的记录
6. 清空历史记录 → 历史搜索区块显示空

### 响应式测试

1. PC 端（≥768px）→ 左侧滑出抽屉，热门/历史两列 grid 布局
2. H5 端（<768px）→ 左侧滑出抽屉，热门/历史横向 flex-wrap 排列

## 技术备注

- **入口**：`BCHeaderBar` 组件中的搜索图标（全局可用）
- **组件**：`BCSearchDrawer`（抽屉内容组件，由 `USlideover` 包裹）
- **布局集成**：在 `layouts/default.vue` 中集成，与 `BCCategoryNav` 使用相同的抽屉交互模式
- **Composable**：`useSearchHistory`（历史记录管理）
- **API**：使用现有 `itemApiClient.getItemList()`，传递 `keywords` 参数
- **URL 参数**：`/collections/all?keyword=xxx`（页面使用 `keyword`，API 使用 `keywords`）
- **存储**：历史记录使用 `localStorage`，key 为 `search_history`
- **防抖**：筛选变化使用 300ms 防抖
- **SEO**：搜索页 title 动态更新为"关键词 - 商品搜索 - ECSHOPX"
