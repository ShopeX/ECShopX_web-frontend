# 需求文档: ECX-8100 个人中心积分展示集成

## 1. 背景
为了简化用户操作路径，取消独立的积分详情页。将会员积分的概览展示与带分页的完整列表全部集成在个人中心首页（Dashboard）。

## 2. 需求摘要
在 `index.vue` (个人中心首页) 实现积分概览及完整的分页积分明细列表。删除 `points.vue` 及相关入口。

## 3. 核心功能
1. **积分概览**: 首页展示可用积分数值，移除跳转链接。
2. **积分流水列表**: 首页下方展示完整积分流水，支持数字翻页。
3. **加载优化**: 切换页码时列表展示骨架屏，无闪动。
4. **清理**: 
   - 删除 `app/pages/account/points.vue`。
   - 移除 `AccountMenu.vue` 中的“我的积分”菜单项。

## 4. 验收标准
1. 进入 `/account` 可直接查看积分流水并翻页。
2. 侧边栏及个人中心卡片无“跳转详情”入口。
3. `/account/points` 路径不可访问。
