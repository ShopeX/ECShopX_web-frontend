# 40-marketing-cms: 营销与内容 Domain

本技能包涵盖了商城的促销活动（优惠券、满减）以及 CMS 动态页面渲染逻辑。

## 1. 营销系统 (Promotion & Coupon)

- **优惠券逻辑**: 
  - 领取校验：有效时间、等级限制、每人限放次数。
  - 使用规则：门槛校验、互斥规则。
- **活动展示**: 
  - 倒计时组件：秒杀/限时抢购。
  - 营销角标：列表页的价格促销标记。

## 2. 内容管理系统 (CMS Rendering)

- **动态渲染架构**: 
  - 基于 JSON 配置动态加载 UI 组件。
  - 支持多版本发布与灰度预览。
- **核心组件**:
  - `CmsPageRenderer.vue`: 解析配置并循环渲染子组件。
  - `CmsSlider`: 动态 Banner。
  - `CmsGrid`: 灵活布局区块。

## 3. UI 组件与校验

- **关键组件**: 
  - `CouponCard.vue`: 优惠券样式。
  - `Countdown.vue`: 可复用的倒计时逻辑。
- **校验逻辑**:
  - 确保营销文案在多语言环境下不超出 UI 容器边界。

## 4. 业务边界
- CMS 页面必须支持 SEO 元数据后置注入。
- 自动化测试：验证“当优惠券过期时，结算页是否正确展示为不可用”。
