# 变更摘要: ECX-8100 会员中心积分功能实现与精化

## 1. 需求背景
实现会员中心个人中心页面的积分概览展示，并开发独立的“我的积分”详情页（支持分页、筛选、积分明细展示），UI 需深度对齐 Figma 设计稿 `2511-10465`。

## 2. 核心改动

### 2.1 基础设施与接口
- **PointApiClient.ts**: 新增积分相关接口封装，包括获取会员积分信息和积分明细列表。
- **useMemberPoint.ts**: 新增业务 Composable，封装积分数据管理、分页逻辑、加载状态和数据格式化。
- **zh-CN.json**: 新增积分页面相关的多语言短语。

### 2.2 页面与 UI
- **index.vue (Dashboard)**:
  - 优化布局与间距，对齐 Figma 规范。
  - 引入骨架屏（USkeleton），解决加载时“暂无记录”闪烁问题。
  - 接入真实积分数据，并支持点击“全部积分”跳转。
- **AccountMenu.vue**:
  - 新增“我的积分”菜单项。
  - 为所有菜单项添加 `data-testid` 属性，增强 E2E 测试可维护性。
- **points.vue (详情页)**:
  - 实现完整的积分流水展示页面。
  - 将“加载更多”模式重构为 **数字分页（ECPagination）** 模式。
  - 将 PC 端侧边栏间距调整为 `64px`，完全还原 Figma 视觉规格。
- **ECPagination.vue**: 重构分页组件 UI 以对齐 Figma。采用了 `32x32` 固定尺寸、全黑激活态背景、Inter 字体，并增加了顶部边框线装饰。

### 2.3 加载与体验
- 优化了加载状态的初始值（loading = true），配合骨架屏实现了无感加载体验。

## 3. 验证结果
- **UI 还原**: PC (1440px) 与 H5 (375px) 均已按照 Figma 节点复刻。
- **分页功能**: 数据翻页正常，页码切换时加载态显示正确。
- **E2E 准备**: 已产出对应的 Playwright 测试用例于 `.f2e-ai/requirements/20260312-ECX-8100/test.spec.ts`。

## 4. 后续建议
- 建议定期进行 E2E 回归测试以确保积分计算及展示的稳定性。
