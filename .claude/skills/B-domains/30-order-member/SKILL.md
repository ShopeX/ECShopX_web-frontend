# 30-order-member: 订单与会员 Domain

本技能包定义了订单生命周期管理、用户权限校验以及个人中心业务逻辑。

## 1. 订单管理 (Order Lifecycle)

- **状态流转**: 待支付 -> 待发货 -> 待收货 -> 已完成/已关闭。
- **物流跟踪**: 
  - 接入第三方物流接口，实时解析并展示轨迹。
  - 核心状态映射：`LogisticsStatus -> ViewStatus`。
- **售后流程**: 申请退款、退货退款的校验与状态同步。

## 2. 会员与鉴权 (Member & Auth)

- **登录流程**: 手机号/验证码登录、第三方登录、Token 刷新机制。
- **资料管理**: 昵称、头像、密码修改、安全绑定。
- **资产概览**: 积分流水、余额记录、会员等级降级规则。

## 3. UI 组件与 Composable

- **关键组件**: 
  - `OrderListCard.vue`: 订单简要信息。
  - `LogisticsTimeline.vue`: 物流时间轴。
  - `UserAssetRow.vue`: 个人资产横条。
- **关键 Composable**:
  - `useAuth`: 统一处理登录态、登出及权限重定向。
  - `useOrderActions`: 包含取消、确认收货、评价等业务操作。

## 4. 权限与安全
- 路由守卫：非登录状态访问 `/member`, `/orders` 等路径强制拦截。
- 敏感操作（如注销账号）需进行二次验证。
