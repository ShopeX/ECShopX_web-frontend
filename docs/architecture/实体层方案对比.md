| 方案           | 自实现装饰器  | class-transformer |

## 📝 代码对比

### 1. 实体定义对比

#### 自实现版本

```typescript
@AutoMap
export class ItemDetailTransformer {
  @Field('item_id')
  itemId!: string

  @Field('price', (price: number) => price / 100)
  price!: number

  @ComputedField('priceDisplay')
  get priceDisplay(): string {
    return `¥${this.price.toFixed(2)}`
  }
}
```

#### class-transformer版本

```typescript
export class ProductEntity {
  @Expose({ name: 'item_id' })
  itemId!: string

  @Type(() => PriceInfo)
  @Transform(({ obj }) => {
    const priceInfo = new PriceInfo()
    priceInfo.current = obj.price || 0
    return priceInfo
  })
  price!: PriceInfo

  // 自动获得复杂的嵌套对象支持
}
```

### 2. 数据转换对比

#### 自实现版本

```typescript
// 手动实现转换逻辑
const transformer = ItemDetailTransformer.fromSource(source)
return transformer.toTarget()
```

#### class-transformer版本

```typescript
// 标准化的转换API
const entity = plainToClass(ProductEntity, source, {
  enableImplicitConversion: true,
  excludeExtraneousValues: true,
})
return classToPlain(entity)
```

## 🚀 class-transformer 的独有优势

### 1. 嵌套对象转换

```typescript
export class ProductEntity {
  @Type(() => PriceInfo) // 🎯 自动处理嵌套对象
  price!: PriceInfo

  @Type(() => CategoryInfo)
  category!: CategoryInfo

  @Type(() => VariantInfo)
  variants!: VariantInfo[] // 🎯 数组元素也自动转换
}
```

### 2. 数据验证集成

```typescript
export class ProductEntity {
  @IsString()
  @Length(1, 100)
  @Expose({ name: 'itemName' })
  itemName!: string

  @IsNumber()
  @Min(0)
  @Transform(({ value }) => value / 100)
  @Expose({ name: 'price' })
  price!: number
}

// 使用
const entity = plainToClass(ProductEntity, data)
const errors = await validate(entity) // 🎯 自动验证
```

### 3. 条件转换

```typescript
export class ProductEntity {
  @Transform(({ obj }) => (obj.status === 'active' ? obj.price : 0))
  @Expose({ name: 'price' })
  displayPrice!: number

  @Exclude({ toPlainOnly: true }) // 🎯 条件性排除
  internalId!: string
}
```

### 4. 分组和版本控制

```typescript
export class ProductEntity {
  @Expose({ groups: ['admin', 'owner'] }) // 🎯 只对特定组暴露
  cost!: number

  @Expose({ since: '1.0.0', until: '2.0.0' }) // 🎯 版本控制
  oldField!: string
}
```
