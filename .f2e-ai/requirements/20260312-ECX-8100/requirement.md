  - API (Apifox): Project 7908795

## 2. 需求摘要

实现页面 UI 开发，对接个人中心积分显示和积分明细。

## 3. 分类结果

- **范围 (Scope)**: S2 (完成会员中心部分 UI 开发，并与后端实际接口联调 - 连通积分显示与明细数据)
- **目标端 (Platform)**: T3 (移动端 + PC 中控/响应式多端支持)
- **UI (设计稿)**: U2 (已有确切的 Figma 链接)
- **API (接口)**: A2 (使用已有的 API：积分列表、获取积分信息)
- **验收方式 (Validation)**: V1 (由前端根据设计稿直接开发并联调，保证页面 UI 高度还原以及数据正确对接渲染)

## 4. 目标用户/场景

- **用户**: PC 端及移动端访问电商系统的注册会员。
- **场景**: 用户进入个人中心后，需要查看当前剩余的积分，以及查看历史积分的获取和消耗流水（积分明细）。

## 5. 核心能力

1. **积分信息展示**: 根据最新接口渲染用户的总积分等数据。
2. **积分流水列表**: 调用接口展示长列表明细（需支持分页或滚动加载）。
3. **响应式设计**: 页面需同时兼容移动端 H5 视图以及 PC 中控视图的展示。

## 6. 验收标准

1. **还原度**: 前端实现与 Figma 链接 100% 对齐（PC端与移动端双端效果还原）。
2. **联调可用**: "获取积分信息"和"积分列表"接口调通，状态处理（加载中、空数据、异常）正确。
3. **交互**: 列表翻页或滚动体验良好。

## 7. 约定与约束

1. 采用项目中现有的统一公共组件实现布局结构。
2. 网络错误时应能给出友好提示保障体验。
