## ✅ 五大核心建议

### 1️⃣ 架构简化（强烈推荐）

**现状问题**：
- 5 层架构（Domain → Application → Infrastructure → Composable → Page）
- 领域事件系统闲置未用
- 开发效率低（改1个功能需要改5个文件）
- 学习成本高（新人需要1-2周）

**优化方案**：
```
❌ 删除：
  - app/domain/ 目录（业务逻辑移到 Composable）
  - app/application/ 目录（用例协调合并到 Composable）
  - 所有领域事件文件（*Event.ts）

✅ 保留：
  - shared/value-objects/ (MoneyValueObject, QuantityValueObject)
  - infrastructure/transformers/ (数据转换)
  - infrastructure/http/clients/ (API 调用)

🆕 简化为：
  Page → Composable (业务逻辑) → Infrastructure → API
```

**预期收益**：
- 开发效率 +60%
- 学习成本 -70%
- 代码量 -40%

---

### 2️⃣ 多模板机制（推荐）

**现状问题**：
- 单一 UI 实现，不支持多套模板
- UI 和业务逻辑耦合

**优化方案**：

```
app/
├── composables/              # 业务逻辑（所有模板共享）
│   └── cart/
│       └── useCartDomain.ts
│
└── components/
    ├── base/                 # 基础组件（跨模板）
    │   └── Button.vue
    │
    └── templates/            # 🆕 多模板系统
        ├── default/          # 默认模板
        │   ├── cart/
        │   │   ├── CartList.vue
        │   │   └── CartItem.vue
        │   └── product/
        │
        ├── minimal/          # 极简模板
        │   ├── cart/
        │   └── product/
        │
        └── luxury/           # 豪华模板
            ├── cart/
            └── product/
```

**核心特性**：
- ✅ 运行时动态切换主题
- ✅ 业务逻辑完全复用
- ✅ UI 完全解耦
- ✅ 易于扩展新模板

**使用示例**：

```vue
<script setup>
// ✅ 业务逻辑所有模板共享
const { cartUIData, updateQuantity } = useCartDomain()
const { getThemeComponent } = useTheme()

// 🎨 根据主题动态加载组件
const CartListComponent = defineAsyncComponent(
  () => import(getThemeComponent('cart', 'list'))
)
</script>
```

   - 输入 `composable` 自动生成模板
   - 输入 `transformer` 自动生成模板

**预期收益**：
- 新人上手时间：1-2 周 → 2-3 天

### 5️⃣ 国际化与RTL支持（推荐）

**方案**: 使用 `@nuxtjs/i18n`

**核心特性**：

1. **多语言支持**
```json
// locales/zh-CN.json
{
  "cart": {
    "title": "购物车",
    "checkout": "去结算"
  }
}

// locales/ar-SA.json
{
  "cart": {
    "title": "عربة التسوق",
    "checkout": "الدفع"
  }
}
```

2. **RTL（从右到左）支持**
```vue
<template>
  <!-- ✅ 使用逻辑属性，RTL 自动反转 -->
  <div class="ms-4">内容</div>
</template>

<style>
.header {
  /* ✅ 逻辑属性，RTL 下自动变为 padding-right */
  padding-inline-start: 16px;
}
</style>
```

3. **配置语言**
```typescript
// nuxt.config.ts
i18n: {
  locales: [
    { code: 'zh-CN', name: '简体中文', dir: 'ltr' },
    { code: 'en-US', name: 'English', dir: 'ltr' },
    { code: 'ar-SA', name: 'العربية', dir: 'rtl' },  // RTL
  ],
  defaultLocale: 'zh-CN',
}
```

**预期收益**：
- ✅ 支持全球化业务
- ✅ 支持中东市场（阿拉伯语）
- ✅ 易于扩展新语言
