# 需求：结算页开发（ECX-8074）

## 需求来源

- **Teambition**：ECX-8074（项目 ECShopX4.0）
- **标题**：结算页开发
- **备注**：任务内无详细说明，以下内容来自多轮需求澄清

## 原文或摘要

- 任务原文：结算页开发（无备注）
- 澄清摘要：**Web 端商城**前台订单结算页，支持从购物车与立即购买双入口进入，同一结算页需具备订单摘要、收货地址（选择/新增/修改）、优惠券选择、支付方式选择及提交订单能力。**仅做 PC 与移动端 H5 的响应式适配，不包含小程序或 APP。**

## 目标用户 / 场景

- **用户**：在 Web 商城（PC 或手机浏览器 H5）完成选购的买家
- **场景**：
  1. 从购物车选择商品后点击「去结算」进入结算页
  2. 从商品详情点击「立即购买」进入结算页
- **目标**：在同一结算页完成地址、优惠券、支付方式选择并成功提交订单

## 核心能力

1. **订单摘要**：展示待结算商品、金额（含运费、优惠等）
2. **收货地址**：展示当前选中地址，支持选择已有地址、新增地址、修改地址；涉及省市区与自提点（若业务需要）
3. **优惠券**：展示可用优惠券列表，选择后体现抵扣与实付金额
4. **支付方式**：展示可选用支付方式（如微信支付等），选择后与下单一致
5. **提交订单**：校验必填项后调用创建订单接口，并引导至支付或结果页

## 验收标准

- [ ] 页面可从购物车、立即购买两种入口正常进入并展示结算页
- [ ] 展示订单摘要：商品信息、金额、运费、优惠等
- [ ] 支持修改/选择/新增收货地址（含省市区、自提点等若设计有）
- [ ] 支持选择优惠券：可用券列表、选中后抵扣与实付展示正确
- [ ] 支持选择支付方式（如微信支付等）
- [ ] 可成功提交订单（调用创建订单接口并处理成功/失败）

## 约束

- **端范围**：当前系统为 Web 端商城，仅实现 PC 与移动端 H5 的响应式适配，不开发小程序或 APP 端。
- 与现有 ECshopX Web 前台技术栈一致（Nuxt/前端现有约定）
- 接口以 Apifox 文档为准（见 api-notes.md）
- UI 以 Figma 设计稿为准（见 ui-notes.md，若有）

## 优先级

- 默认：高（结算为下单关键路径）
- 若与迭代规划冲突，以项目排期为准

## 待确认项

- [ ] 自提点是否在本需求必做（接口已提供，是否首屏必选）
- [ ] 支付方式除微信外是否还有其它（仅展示 or 需联调）
- [ ] 错误态与空态（无地址、无可用券等）是否按设计稿或统一规范
