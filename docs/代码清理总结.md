# 代码清理总结

## 📋 清理概述

在架构从完整 DDD 迁移到轻量级 DDD 后，对旧架构的代码进行了彻底清理，删除了不再使用的文件和目录。

**清理日期**: 2025-01-XX

---

## ✅ 已删除的文件

### 1️⃣ Domain 层（购物车）- 共 7 个文件

#### 聚合根和实体
- ❌ `app/domain/cart/Cart.ts` - 购物车聚合根
- ❌ `app/domain/cart/CartItemEntity.ts` - 购物车商品实体

**原因**: 新架构使用简单的接口（`ICartItemModel`, `ICartModel`）替代复杂的领域模型。

#### 领域服务
- ❌ `app/domain/cart/CartPolicyService.ts` - 购物车领域服务

**原因**: 业务逻辑已合并到 `useCart` composable 中，不再需要单独的领域服务。

#### 仓储接口
- ❌ `app/domain/cart/ICartRepository.ts` - 购物车仓储接口

**原因**: 新架构不使用仓储模式，直接使用 HTTP Client。

#### 领域事件
- ❌ `app/domain/cart/CartItemAddedEvent.ts` - 商品添加事件
- ❌ `app/domain/cart/CartItemRemovedEvent.ts` - 商品移除事件
- ❌ `app/domain/cart/CartItemQuantityChangedEvent.ts` - 数量变更事件

**原因**: 新架构不使用领域事件，使用更简单的状态管理。

---

### 2️⃣ Application 层（购物车）- 共 5 个文件

#### 应用服务
- ❌ `app/application/cart/CartApplicationService.ts` - 购物车应用服务

**原因**: 应用层逻辑已合并到 `useCart` composable 中。

#### DTOs（数据传输对象）
- ❌ `app/application/cart/dto/AddToCartDto.ts` - 添加到购物车 DTO
- ❌ `app/application/cart/dto/UpdateCartDto.ts` - 更新购物车 DTO
- ❌ `app/application/cart/dto/RemoveCartDto.ts` - 删除购物车 DTO
- ❌ `app/application/cart/dto/index.ts` - DTO 导出文件

**原因**: 新架构不使用 DTO 层，直接使用 API 类型定义（如 `IAddCartRequest`）。

---

### 3️⃣ Composable（旧版本）- 共 1 个文件

- ❌ `app/composables/domain/cart/useCartDomain.ts` - 旧版购物车 composable

**原因**: 已被新的 `useCart` composable 完全替代。

**对比**:

| 项目 | 旧版 useCartDomain | 新版 useCart |
|------|-------------------|--------------|
| **依赖** | CartApplicationService, CartHttpRepository, CartPolicyService | 直接使用 CartApiClient |
| **数据模型** | Cart (聚合根) | ICartModel (简单接口) |
| **复杂度** | 高（多层调用） | 低（扁平化） |
| **代码量** | ~300 行 | ~550 行（包含业务逻辑） |

---

### 4️⃣ Infrastructure 层（仓储）- 共 1 个文件

- ❌ `app/infrastructure/repositories/CartHttpRepository.ts` - 购物车 HTTP 仓储实现

**原因**: 新架构直接使用 `CartApiClient`，不需要仓储模式的额外抽象层。

**数据流对比**:

```
旧架构: Composable → Application Service → Repository → HTTP Client
新架构: Composable → HTTP Client
```

---

### 5️⃣ 旧的 Shared 文件 - 共 4 个文件

- ❌ `app/domain/shared/MoneyValueObject.ts` - 金额值对象（旧）
- ❌ `app/domain/shared/QuantityValueObject.ts` - 数量值对象（旧）
- ❌ `app/domain/shared/DomainError.ts` - 领域错误（旧）
- ❌ `app/domain/shared/DomainEvent.ts` - 领域事件基类

**迁移到**:
- ✅ `app/shared/value-objects/MoneyValueObject.ts` - 新位置
- ✅ `app/shared/value-objects/QuantityValueObject.ts` - 新位置
- ✅ `app/shared/errors/BusinessError.ts` - 重命名并迁移
- ❌ 领域事件不再使用

---

### 6️⃣ Product 模块（已重构）- 共 3 个文件

- ❌ `app/composables/domain/product/index.ts` - 导出文件
- ❌ `app/composables/domain/product/useProductList.ts` - 商品列表 composable
- ❌ `app/composables/domain/product/useProductDetail.ts` - 商品详情 composable

**重构为**:
- ✅ `app/composables/useProduct.ts` - 合并列表和详情功能

**原因**:

- 详见 [Product模块重构总结.md](./Product模块重构总结.md)

  // 1. 定义状态
